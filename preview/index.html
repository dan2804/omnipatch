MIDI Engine & Synth Profile Architecture

How MidiQuest in Rust maps PDF manuals to cross-platform SysEx engines.

Rust Backend Core (midir + pacing)

`midir` handles platform audio subsystems directly without bloated C++ runtimes:

  • Windows: WinMM or WinRT MIDI
  • macOS: CoreMIDI framework
  • Linux: ALSA sequencer & raw MIDI
  • FreeBSD/OpenBSD: JACK audio or sndio layer
pub struct VirusMessage {
  device_id: u8, // 0x10 = omni
  page: VirusPage,  // 0x70=A, 0x71=B, 0x72=C
  part: u8,       // 0x40 = single edit buffer
  param_id: u8,   // 0..127
  value: u8,      // 7-bit MIDI byte
}
